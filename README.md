Welcome to my personal code library! This is where I store reusable code snippets, games, utilities, and study notes as I learn Python and Java.

## 📚 What's Inside?

### Python
- **Games** - Fun game projects and logic
- **Utilities** - Helpful functions and tools
- **Study Notes** - Learning notes and concepts

### Java
- **Games** - Game implementations in Java
- **Utilities** - Useful Java methods and classes
- **Study Notes** - Java concepts and learning notes

### Examples
- Sample code and demonstrations

## 🚀 How to Use This Library

1. Browse the folders for code you need
2. Copy and modify the code for your projects
3. Check study notes when learning new concepts
4. Run examples to see how things work
