# Python Utilities

This folder contains reusable helper functions that you can copy and use in your own projects.

## Files

### helpers.py
Basic utility functions for common tasks:
- `is_even(number)` - Check if a number is even
- `is_odd(number)` - Check if a number is odd
- `reverse_string(text)` - Reverse a string
- `factorial(n)` - Calculate factorial

## 📖 How to Use

### Option 1: Copy and Paste
Just copy the function you need into your own Python file.

### Option 2: Import
You can import the helpers file:

```python
from helpers import is_even, reverse_string

print(is_even(4))  # True
print(reverse_string("hello"))  # "olleh"
```
