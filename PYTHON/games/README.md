# Python Games

This folder contains game projects to learn Python through fun!

## Files

### simple_number_game.py
A simple guessing game where the computer picks a random number and you try to guess it.

**What you learn:**
- Random number generation
- Loops (while loops)
- Conditionals (if/else statements)
- User input
- Comparisons

**How to play:**
```bash
python simple_number_game.py
```

Then follow the prompts to guess the number!
