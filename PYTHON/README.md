# Python Code Library

This folder contains all my Python learning and code snippets.

## 📂 Folders

### Games
Fun game projects written in Python. Perfect for learning loops, conditionals, and functions.

### Utilities
Reusable helper functions for common tasks like:
- String manipulation
- Math operations
- List/array operations
- Data checking

### Study Notes
Learning notes and explanations of Python concepts:
- Variables and data types
- Loops and conditionals
- Functions and methods
- Object-oriented programming

## 🎯 Getting Started

1. Look at the example files first
2. Read the study notes to understand concepts
3. Try running the games
4. Modify the utilities for your own projects

## 💻 Running Python Files

To run a Python file from your computer:

```bash
python filename.py
```

Make sure you have Python installed first!
