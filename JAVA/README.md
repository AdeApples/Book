# Java Code Library

This folder contains all my Java learning and code snippets.

## 📂 Folders

### Games
Fun game projects written in Java. Great for learning classes, methods, and logic.

### Utilities
Reusable helper methods for common tasks like:
- String manipulation
- Math operations
- Array operations
- Data validation

### Study Notes
Learning notes and explanations of Java concepts:
- Variables and data types
- Loops and conditionals
- Functions and methods
- Object-oriented programming

## 🎯 Getting Started

1. Make sure you have Java installed
2. Look at the example files first
3. Read the study notes to understand concepts
4. Try compiling and running the games
5. Modify the utilities for your own projects

## 💻 Running Java Files

To compile and run a Java file:

```bash
javac FileName.java    # Compile
java FileName          # Run
```

Make sure you have Java Development Kit (JDK) installed!
