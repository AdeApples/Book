# Java Games

This folder contains game projects to learn Java through fun!

## Files

### SimpleNumberGame.java
A guessing game where the computer picks a random number and you try to guess it.

**What you learn:**
- Classes and main method
- Random number generation
- Loops (while loops)
- Conditionals (if/else statements)
- User input with Scanner
- Method organization

**How to play:**
```bash
javac SimpleNumberGame.java
java SimpleNumberGame
```

Then follow the prompts to guess the number!
